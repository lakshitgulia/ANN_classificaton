# ANN Classification – Customer Churn Prediction

A binary classification project using an Artificial Neural Network (ANN) built with TensorFlow/Keras to predict whether a bank customer will churn (leave the bank) based on their profile and account details.

## 📌 Project Overview

**Objective:** Predict customer churn (Exited: Yes/No) using the Churn Modelling dataset.

**Concepts Covered:**
- Data preprocessing (encoding categorical variables, feature scaling)
- Label Encoding & One-Hot Encoding
- Feature Scaling (StandardScaler)
- Artificial Neural Network (ANN) architecture
- Model training & evaluation
- Model inference on new data

**Tech stack:** Python, TensorFlow, Keras, NumPy, Pandas, Scikit-learn, TensorBoard, SciKeras

## 📊 Dataset
The dataset (`Churn_Modelling.csv`) contains customer information such as credit score, geography, gender, age, tenure, balance, number of products, and whether the customer exited the bank.
